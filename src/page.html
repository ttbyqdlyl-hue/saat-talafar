أهلاً بيك

اكتب باسورد اللوحة حتى تدير منتجات المحل ومعلوماته.

نسيت الباسورد؟ اللي سوّالك الموقع يكدر يرجّع اللوحة لشاشة التجهيز، وتختار باسورد جديد.

ماكو اتصال بالإنترنت

اللوحة تحتاج نت حتى تفتح. تأكد من الاتصال واضغط «جرّب مرة ثانية».

مفتاح GitHub انتهى

الباسورد صحيح، بس مفتاح GitHub اللي بداخل اللوحة انتهت صلاحيته. سوّي مفتاح جديد بنفس الخطوات والصقه هنا، والباسورد يبقى نفسه.

  1. افتح صفحة مفتاح GitHub جديد.
  2. Only select repositories ← saat-talafar، وContents ← Read and write.
  3. اضغط Generate token وانسخ المفتاح.

تجهيز اللوحة (مرة وحدة بس)

هاي الخطوة يسويها صاحب الموقع مرة وحدة. بعدها صاحب المحل يدخل بالباسورد بس.

  1. افتح صفحة مفتاح GitHub جديد وأنت داخل بحساب ttbyqdlyl-hue.
  2. بخانة Repository access اختار Only select repositories ثم saat-talafar.
  3. بخانة Permissions اختار Contents وخليها Read and write، وخلي مدة الانتهاء أطول شي.
  4. اضغط Generate token، انسخ المفتاح، والصقه هنا.
